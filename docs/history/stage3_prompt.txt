=========================================

Implement a two-state Markov-switching model.

Regime 1: Low volatility
Regime 2: High volatility

Use statsmodels or another appropriate
well-supported library.

Model daily log returns with:
- Two latent regimes
- Regime-specific conditional variance
- Estimated transition probabilities
- Filtered regime probabilities
- One-step-ahead variance predictions

Start with a zero-mean specification.

CRITICAL:
Use filtered probabilities available at
forecast origin, not full-sample smoothed
regime probabilities.

Do not classify historical regimes using
future observations in the forecasting path.

Estimate the transition matrix from training
data only.

At time t, use the filtered state probabilities
and transition matrix to obtain the predictive
state probabilities for t+1.

Calculate the corresponding forecast variance.

Use configurable rolling training windows
and a documented re-estimation schedule.

Between refits, ensure the filtering state
incorporates newly observed returns without
using future observations.

Handle label switching, convergence failures
and unstable regime estimates.

Record model failures explicitly.
